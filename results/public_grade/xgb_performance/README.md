# XGBoost 모델 성능 요약 (학습 건별)

> 현재 학습 건은 모두 **개발용 실험**(이미 본 데이터)이다. 성능 근거가 아니며, 모델은 배포·API에 연결하지 않는다.

| 파일 | 내용 |
|---|---|
| `xgb_performance_index.csv` | **학습 건 목록.** 한 건당 한 줄: 학습 건 이름, 학습일, 데이터셋, 입력 지문, Window 수, 모델 수, 원본·열화본 평균 AUC·오경보율·위험 탐지율·등급 정확도, 성능표 파일, 모델 폴더, 코드 커밋 |
| `<학습 건>.csv` | 그 학습 건의 모델별 성능표 (모델 16개 + 원본·열화본 × 과제별 평균) |
| `<학습 건>_summary.json` | 그 학습 건의 상세 요약 (입력 파일 MD5, 설정값, 조건별 지표, 중요 특징값) |

**학습 건 이름:** `<데이터셋>_<학습일>_<입력 지문 8자리>` (예: `hbta_sm_20261119_41906402`)

**쌓이는 규칙:** 입력 지문 = 입력 파일 MD5 + 입력 특징값 목록 + 설정값 + 평가 방식.
- 새 데이터(또는 바뀐 설정)로 학습하면 새 지문 → **새 학습 건으로 추가**, 이전 학습 건은 그대로 남는다.
- 같은 데이터·같은 설정으로 다시 실행하면 같은 지문 → 기존 학습 건을 다시 만들고 **쌓지 않는다.**

모델 파일, Window별 예측, 학습 데이터셋은 `data/processed/public_grade/xgb_runs/<학습 건>/`에 있다 (git 제외).

실행: HBTA 스윕 가진 `.venv/bin/python -m src.public_grade.xgb_sm_experiment`, HBTA 노이즈 가진 `.venv/bin/python -m src.public_grade.xgb_nm_experiment`. 공통 엔진은 `src/public_grade/xgb_engine.py`이고, 새 데이터셋은 불러오기와 평가 나누기 설정(Spec)만 추가하면 같은 구조로 쌓인다


**Ponte Moesa 학습 건 주의 (2026-11-20):** `ponte_moesa_*` 학습 건의 "정상"(DS2)은 철근을 노출한 손상 상태다. 정상 vs 손상이 아니라 "철근 노출(굴착기 작업 중) vs 더 큰 손상"으로 읽고, 오경보율은 진짜 오경보가 아니다. `docs/AI2_PONTE_MOESA_BASELINE_NOTE.md`
