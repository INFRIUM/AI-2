# Ponte Moesa 기준 상태: DS2는 정상이 아니라 "기준 상태(주의)"이고, DS2 대비 변화를 판별한다

작성일: 2026-11-20 (AI① 확인 반영) · 관련: #15, #19, #21, PR #22 · 대상: Ponte Moesa (Box, `AI1-public-1.1`)

## 1. 결정

| 항목 | 이전 | 바로잡음 |
|---|---|---|
| DS2 (철근 I·II·III 노출)의 역할 | "정상" | **"기준 상태."** 우리가 쓰는 센서 위치(setup 5)가 설치된 뒤의 첫 상태 |
| DS2의 절대 등급 | 정상 | **주의 (경미한 손상)**. 손상 기록상 철근이 노출된 상태 |
| 판별 방식 | 정상 대비 손상 | **기준 상태(DS2) 대비 변화.** DS3·DS5·DS7이 DS2보다 나빠졌는지를 판별 |
| Ponte Moesa의 정상 상태 | DS2 | **없음.** 데이터셋 전체에 손상 없는 측정이 없음 (AI① 확인, 2절) |
| 정상 상태 학습 | DS2로 학습 | **불가.** DS2 자체가 정상인지는 판별할 수 없음 |
| 기준 대비 오경보 | "오경보" | **의미 있는 지표로 봄.** 기준 상태에서 변화가 없는데 변했다고 판정한 비율. 다만 "정상을 이상으로 판정한 비율"은 아님 |

## 3. 판별 방식: DS2 기준 대비 변화

| 질문 | DS2를 기준으로 판별하면 |
|---|---|
| DS3, DS5, DS7이 DS2보다 더 나빠졌는가 | ✅ 판별 가능 |
| DS2 측정 중 기준을 넘는 경우가 있는가 (기준 대비 오경보) | ✅ 확인 가능 |
| DS2 자체가 정상인가 | ❌ 판별 불가. 손상 기록으로 "주의"임을 알 뿐 |

**실제 운영과 같은 방식이다.** 이미 쓰고 있는 교량에 센서를 설치하면, 설치한 날의 상태가 기준 상태가 된다(이미 열화가 있을 수 있음). 이후 기준보다 나빠지는지를 감시하고, 기준 상태가 건강한지는 점검으로 따로 판단한다. Ponte Moesa에서 초기 손상(DS0, DS1) 뒤 센서를 설치하고 DS2를 기준으로 쓰는 것과 같다.

| 상태 | 손상 기록상 절대 등급 | 기준 대비 판별 (AI② 시스템) |
|---|---|---|
| DS2 | 주의 (철근 노출) | 기준 (변화 없음) |
| DS3 | 철근 절단 + 천공 | 기준 대비 변화 |
| DS5 | 긴장재 절반 절단 | 기준 대비 변화 |
| DS7 | 긴장재 전체 절단 + 천공 | 기준 대비 큰 변화 |

## 5. 남는 문제: 기준 데이터가 약하다

판별 방식(DS2 기준)은 맞지만, **Ponte Moesa의 DS2 기준 데이터 자체가 약하다.**

- 열화본에서 쓸 수 있는 DS2는 거의 AMB_18(11/27 오후, **굴착기 작업 중**)뿐이다. 다른 DS2 측정(11/26 저녁, 11/27 오전)은 센서 4번이 없는 설치라 모두 판정 보류다.
- 그래서 XGBoost 실험에서 모델이 "굴착기 진동 = 기준"을 배웠고, 가장 심한 손상 DS7을 기준처럼 판정했다(DS7 묶음 AUC 0.10).
- 손상 단계마다 측정일도 다르다(DS3·DS5 11/28, DS7 11/29).

따라서 Ponte Moesa는 **기준 대비 변화의 개발용 참고**로만 쓰고, Box 방법 선정 근거로는 쓰지 않는다.

## 6. Box의 정상 상태

**Box의 정상 상태는 Z24에서만 학습한다.** Z24 사전 등록서에는 처음부터 다음처럼 정의한다.

- 기준 상태 = 정상 = 손상 시험 전 상시 계측 (손상 없는 상태). 여러 날·계절·온도를 포함
- 손상 시험 데이터는 사전 등록 전에 보지 않음
