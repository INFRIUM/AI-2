# Ponte Moesa 기준 상태 재분류: DS2는 정상이 아니다

작성일: 2026-11-20 · 관련: #19, #21, PR #22 · 대상: Ponte Moesa (Box, `AI1-public-1.1`)

## 1. 결정

| 항목 | 이전 | 바로잡음 |
|---|---|---|
| DS2 (철근 I·II·III 노출) | "정상" (기준 상태) | **"주의" (경미한 손상)**. 손상 없는 상태가 아니다 |
| Ponte Moesa의 정상 상태 | DS2 | **없음** (전달받은 데이터 기준) |
| 정상 상태 학습 | DS2로 학습 | **불가.** 정상 데이터가 없으므로 정상을 배울 수도, 오경보(정상을 이상으로 잘못 판정하는 비율)를 잴 수도 없다 |

DS2는 데이터셋에서 "기준 상태"로 쓰인 가장 앞선 상태지만, 이미 철근을 노출한 손상 상태다. AI② 등급 체계에서는 경미한 손상인 "주의"에 해당한다.

## 2. 이유

| 근거 | 내용 |
|---|---|
| 손상 내용 | DS2 = 철근 I·II·III 노출 (`stage_description`). 콘크리트 덮개를 걷어낸 상태 |
| 앞선 상태 없음 | 전달받은 측정의 손상 상태는 DS2, DS3, DS5, DS6, DS7뿐. AI①이 공식 목록과 논문 그림이 맞지 않아 제외한 측정(AMB_2–6, AMB_19–24, AMB_32–33, AMB_46) 중 일부가 DS2보다 앞선 상태일 수 있으나 확인되지 않음 (4절) |
| 기준 측정의 한계 | 열화본에서 쓸 수 있는 DS2 Window는 거의 AMB_18 (11/27 오후, **굴착기 작업 중**)뿐. 다른 날(11/26 저녁, 11/27 오전)의 DS2 측정은 센서 4번이 없어 모두 판정 보류 |

지금까지 Ponte Moesa 결과는 모두 DS2를 정상으로 놓고 계산했다. 숫자는 그대로 두고 **해석을 아래처럼 바꾼다.**

| 결과 | 원래 해석 | 바로잡은 해석 | 문서 |

| v1 Box 검증 (사전 등록) | 정상 대비 손상 등급, 오경보 17.2% | **"철근 노출 상태 대비 변화."** 오경보는 진짜 오경보가 아니라 "DS2 test가 DS2 기준을 넘은 비율" | `docs/AI2_PUBLIC_GRADE_RESULT_v1.md` (사전 등록서는 고치지 않음, 결과 문서 끝에 해석 추가) |

## 4. Ponte Moesa의 역할

| 쓸 수 있는 것 (개발용) | 쓸 수 없는 것 |
|---|---|
| 손상 진행 순서 확인: DS2 < DS3 < DS5 < DS7로 갈수록 지표가 커지는가 | 정상 상태 학습 |
| 손상끼리의 상대 비교 | 정상/이상 구분, 오경보율 |

등급으로 나눈다면 예를 들어 DS2 주의, DS3 경고, DS5·DS7 위험이 될 수 있다. 다만 결과를 본 뒤 정하는 기준이므로 개발용 참고로만 쓴다.

**확인 요청 (AI①):** 원본에 DS2보다 앞선 상태(손상 전)가 있는지, AMB_2–6이 무슨 상태였고 왜 제외했는지 (#15). 손상 없는 상태가 있고 쓸 수 있다면 Ponte Moesa에도 정상이 생긴다.

## 5. Box의 정상 상태

**Box의 정상 상태는 Z24에서만 학습한다.** Z24 사전 등록서에는 처음부터 다음처럼 정의한다.

- 정상 = 손상 시험 전 상시 계측 (손상 없는 상태). 여러 날·계절·온도를 포함
- 손상 시험 데이터는 사전 등록 전에 보지 않음
