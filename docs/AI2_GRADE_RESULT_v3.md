## 3. 해석

| 데이터셋 | 등급이 손상을 따라가는가 | 정상이 정상으로 나오는가 | 요약 |
|---|---|---|---|
| HBTA NM | 대체로 (DS8·DS2·DS6·DS7 높음, DS4·DS5 낮음) | 아니요 (35% 주의 이상) | 4개 중 가장 나음. 열화본 잡음이 한계 |
| HBTA SM | 아니요 | 예 | 지표가 스윕 가진에서 손상을 보지 못함 |
| Ponte Moesa | 아니요 (DS7 6%) | 아니요 (26%) | 지표가 측정 시점·작업 진동에 반응 |
| Old ADA | 예 (손상 100%) | 아니요 (속도 변화 68%) | 정상 기준에 속도 변화가 없음 |

- **v3로 모든 Window에 등급을 매길 수 있다.** 다만 이 결과는 "이 규칙을 적용하면 이렇게 나온다"는 판정 결과이고, 등급이 맞다는 증거가 아니다.
- 데이터셋마다 실패 이유가 다르지만 공통점은 **정상 기준이 실제 정상의 변동(날짜, 작업 진동, 속도)을 충분히 담지 못한다**는 것이다.
