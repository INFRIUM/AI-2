## 2. 상태별 결과 (정상 기준 Window 제외)

표의 값은 판정된 Window 중 비율이다. **주의 이상** = 주의·경고·위험, **경고 이상** = 경고·위험. 괄호는 원본(비교용).

| DS1 | 82 | 48% (49%) | 34% (32%) | 0% (10%) |

- 판정한 3개 데이터셋 중 등급이 손상과 가장 잘 맞는다. DS8, DS2, DS6, DS7은 대부분 주의 이상이다.
- 하지만 **정상 test의 35%도 주의 이상**으로 나온다(경고 이상 24%). 열화본에서는 정상과 손상이 겹친다.
- 원본에서는 DS2·DS8이 98% 위험, 정상 test는 15%만 주의 이상이다. 저가형 센서 잡음이 등급을 흐린다.

### Box: Ponte Moesa: 판정 대상에서 제외 (2026-11-20)

Ponte Moesa에는 **정상 상태가 없다.** 우리 센서 위치(setup 5)가 설치된 뒤의 첫 상태 DS2는 철근을 노출한 손상 상태이고, 그 이전 상태 DS0·DS1도 손상 상태다(AI① 원본 확인). 정상 기준이 없으면 정상/이상 등급을 정의할 수 없으므로, **Ponte Moesa는 v3 판정 대상에서 뺐다.** 성능이 나빠서가 아니라 정상 기준 데이터가 없어서다.

- 2026-11-19에 DS2를 정상으로 놓고 계산한 Box 판정 결과는 **무효**로 처리하고, Window별 결과 파일도 지웠다.
- Ponte Moesa는 손상 진행 순서 확인(DS2 → DS3 → DS5 → DS7)의 개발용 참고로만 쓴다.
- Box의 정상·등급 평가는 Z24(손상 시험 전 상시 계측)로만 한다. `docs/AI2_PONTE_MOESA_BASELINE_NOTE.md`

## 3. 해석

| 데이터셋 | 등급이 손상을 따라가는가 | 정상이 정상으로 나오는가 | 요약 |
|---|---|---|---|
| HBTA NM | 대체로 (DS8·DS2·DS6·DS7 높음, DS4·DS5 낮음) | 아니요 (35% 주의 이상) | 3개 중 가장 나음. 열화본 잡음이 한계 |
| HBTA SM | 아니요 | 예 | 지표가 스윕 가진에서 손상을 보지 못함 |
| Ponte Moesa | - | - | **판정 대상 아님** (정상 상태 없음) |
| Old ADA | 예 (손상 100%) | 아니요 (속도 변화 68%) | 정상 기준에 속도 변화가 없음 |

- **v3로 모든 Window에 등급을 매길 수 있다.** 다만 이 결과는 "이 규칙을 적용하면 이렇게 나온다"는 판정 결과이고, 등급이 맞다는 증거가 아니다.
- 데이터셋마다 실패 이유가 다르지만 공통점은 **정상 기준이 실제 정상의 변동(날짜, 속도)을 충분히 담지 못한다**는 것이다.
