### 2. 위험등급 쪽 주의점

- 조사한 논문 중 4단계 위험등급 식을 제시한 것은 없었습니다. AI②는 정상 대비 변화량으로 직접 설계합니다(3절).
- 주의·경고·위험을 나누려면 **손상 크기가 단계별로 다른 데이터**가 필요합니다. 없으면 정상/이상 2단계만 검증하고, 나머지 구분은 검증 전 (안)으로 둡니다(6절).
- 검증을 통과하기 전에는 `risk_score`, `risk_level`을 null로 둡니다.

### 3. 데이터셋 조건 정정

7167626089에서 유료 논문과 축소 모형 조건이 #25 본문과 다르게 적용되었습니다. #25 본문 기준은 다음과 같습니다.

- **유료 논문은 포함**합니다. 학교 계정으로 받을 수 있는지 AI②가 확인하겠습니다.
- **실제 교량 측정만** 개발 후보로 둡니다.
- **Wan 트러스 모형:** 손상 크기 3단계가 있어 위 2절 등급 경계 설계에 가장 쓸모가 있습니다. 실제 교량이 아니므로 **개발용(등급 경계 설계 참고)으로만 쓰고, 검증은 실제 교량 또는 HW로 하는 것**을 제안합니다. 의견 부탁드립니다.

### 4. 요청

- **AI①:** 3절 Wan 모형 의견, 적용 조건표에 AI② 칸 추가
- **HW:** 센서 종류·개수·위치·샘플링 확정값, 여러 날·재조립을 포함한 정상 측정 일정, 검증용 알려진 손상 조건(가능하면 손상 크기 단계별)
- **BE:** 위험점수·위험등급이 null인 경우(검증 전, 판정 보류) 화면 표시 방식
