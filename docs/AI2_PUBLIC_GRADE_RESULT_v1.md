T2–T4가 T1보다 작고 순서도 뒤집혀 있다. 손상 상태의 지표가 정상 기준 상한(T1)보다 낮다는 뜻이다. T1 불확실성: 보정 72개, 최댓값 0.834, 부트스트랩 90% 구간 [0.708, 0.831].

**통과 조건**

| # | 조건 | 결과 |

Box 등급 전체 잠정 표시 조건(정상 test 30개 미만)에도 해당한다.

**지정 확인 (원본)**

| 확인 | 결과 | 규칙에 따른 처리 |
|---|---|---|
| 3.4 작업 영향 | 원본 T1 = 0.670. 작업 전 test **11/22** 초과(기준: 2개 이상), 작업 중 25/58 (43.1%) | "정상 기준이 작업 진동에 의존" 한계 기록 |
| 3.5 세션 차이 | 2-3 z 중앙값: 11/26 저녁 0.935(49개), 11/27 낮 0.561(40개), 차이 **0.374** | DS3(+0.129), DS5(+0.264), DS7(+0.191) 모두 세션 차이보다 작음 → 세 등급 모두 잠정 |

**해석**

- 1-TAC 기준 전달함수는 `AMB_18` train 구간에서 계산한다. 같은 측정에서 바로 이어지는 보정 블록은 값이 낮고(0.468), 같은 날의 다른 측정(작업 전 `AMB_16` 0.670, `AMB_17`은 열화본에서 전부 판정 보류)과 작업 중 블록(0.643)은 더 높다. 지표가 손상보다 **측정 시점과 작업 진동의 차이**를 더 크게 따라간다.
- 원본에서도 작업 전 test 절반이 원본 T1을 넘고, 세션 차이가 모든 손상 변화보다 크다. 이것은 센서 잡음 문제가 아니다. 이 설계(단일 측정 구간을 기준으로 삼는 1-TAC)의 한계다.
- `AMB_28`(DS3 묶음 A)의 약 15Hz 피크는 1-TAC 대역(3–12Hz) 밖이라 이 결과에 영향을 주지 않았다. DS3 묶음 A의 중앙값(0.587)은 묶음 B(0.654)보다 낮다.

**임계값**

T1 불확실성: 보정 32개, 최댓값 6.681, 상위 3개 6.681·4.494·4.363, 부트스트랩 90% 구간 [3.866, 6.681]. 최댓값 하나가 크게 튀어 있어 T1이 불안정하다.

**상태별 (모두 82개, 판정 보류 0)**

**통과 조건**

| # | 조건 | 열화본 z | 원본 z (참고) | 원본 y+z (참고) | 원인 (사전 등록 규칙) |
|---|---|---|---|---|---|
| 1 | 정상 오경보율 ≤ 5% | **실패** 23.5% (8/34) | 실패 5.9% | 실패 5.9% | 지표 또는 데이터 한계 |
| 2 | 위험 탐지율 ≥ 95% | **실패** 70.1% (DS2 59.8%, DS8 80.5%) | 통과 95.7% | 통과 100% | **센서 잡음** |
| 3 | 등급 순서 | **실패** 주의 4.208 > 경고 4.189 | 실패 | 통과 | **y축 손실** |
| 4 | 손상 범위 순서 | **실패** DS4 < DS3, DS7 < DS6 | 실패 | 실패 | 지표 또는 데이터 한계 |
| 5 | 상태 일반화 | **실패** 8/8 | 실패 | 실패 | 지표 또는 데이터 한계 |

- 위험 등급으로 판정된 비율은 0%다. 임계값 순서가 뒤집혀 상태 제외 검증에서 등급을 매길 수 없었다.
- 세션 차이(열화본 z): `UDS_01` 3.473, `UDS_02` 3.572, 차이 0.098. `UDS_01`만 쓴 참고 결과: T1 4.396, 오경보 3/17 (17.6%).
- 온도: DS3 21°C, DS4 22°C, 나머지 10–14°C. DS4가 정상보다 낮은 점(3.495)은 온도 차이와 겹친다.

**비교 지표: 1-TAC z (참고)**

오경보 10.0% (3/30), 위험 탐지 16.7%, 등급 순서와 손상 범위 순서 실패. AR 거리보다 분리가 약하다.

**해석**

- AR 거리는 정상이 가장 낮고 위험(DS8)이 가장 높은 큰 방향은 맞다. 하지만 정상과 손상이 많이 겹친다.
- 원본 z에서는 위험 탐지 95.7%를 통과하고 열화본 z에서는 70.1%로 떨어진다. **LIS2DW12 잡음이 탐지를 낮췄다.**
- 원본 y+z에서는 등급 순서가 맞는다. **y축을 쓰지 못하는 것**(열화본 y축은 818/820 Window가 판정 보류)이 순서를 깨뜨린 원인이다.
- 원본 y+z에서도 오경보 5.9%, 손상 범위 순서와 상태 일반화가 실패한다. 센서를 바꿔도 2개 센서로는 이 조건을 넘기 어렵다는 설계 v0 6절의 예상과 맞는다.

## 5. Old ADA (점검용, 통과 판정 없음)

참고선은 AI② 기준 3회의 최댓값이다. 표의 값은 참고선을 넘은 주행 수다.

| 상태 | 원본 1-TAC | 열화본 1-TAC | 원본 AR 거리 | 열화본 AR 거리 |
|---|---|---|---|---|
| INT 40km/h test (3회) | 0/3 | 0/3 | 2/3 | 2/3 |
| DMG1 (12회) | 11/12 | 9/12 | 2/12 | 3/12 |
| DMG2 (10회) | 10/10 | 10/10 | 3/10 | 3/10 |
| DMG3 (10회) | 10/10 | 10/10 | 6/10 | 6/10 |
| 속도 영향 확인용 (16회) | **11/16** | 7/16 | 7/16 | 7/16 |
| RCV (참고, 10회) | 8/10 | 5/10 | 5/10 | 4/10 |

- **1-TAC:** 원본 test 중앙값 순서가 INT < DMG1 < DMG2 < DMG3로 손상 순서와 같다. DMG1도 11/12가 참고선을 넘어, "DMG1은 탐지되지 않을 수 있음"이라는 사전 기록과 다르다. 그러나 손상이 없는 30·50km/h 주행도 11/16이 참고선을 넘는다. 따라서 **손상 효과와 속도 효과를 구분할 수 없다.** 참고선이 3회의 최댓값이라는 점도 함께 고려해야 한다.
- **AR 거리:** 정상 test(40km/h)가 손상보다 높게 나와 순서가 맞지 않는다. 기준이 train 4회라 거리가 불안정하다.
- 열화본은 단위가 m/s²라는 간접 추정을 전제로 한다. gal이면 열화본은 전부 판정 보류에 해당한다.

## 6. 의미와 다음 단계

- **사전 등록 규칙대로 두 교량 모두 공개 데이터 기준 등급 출력이 불가하다.** 이 결과는 AI② 코드나 모델이 "준비되지 않았다"는 기존 출력(`MODEL_NOT_READY`, `risk_level = null`)과 일치한다.
- 이 결과를 바탕으로 지표나 기준을 바꿔 다시 시도하려면 **v2 사전 등록서**를 새로 쓰고, 결과에 "결과 열람 후 변경"을 표시해야 한다.
- HW 모형 실험 설계에 주는 시사점(규칙 변경 아님):
  - Box: 기준 상태를 측정 하나의 연속 구간으로 잡으면 다른 측정에서 오경보가 커진다. 손상 전 기준을 **여러 번, 여러 시점에** 측정해야 한다.
  - Truss: 열화본에서 탐지가 떨어지고 y축이 보류되었다. 모형 실험에서는 **가진 크기를 LIS2DW12 잡음보다 충분히 크게** 해야 한다(합의서 v3 2절 "모형 y축 신호가 보류 기준을 넘는지").
  - Old ADA: 가진 조건(속도)이 1-TAC를 크게 바꾼다. 모형 실험에서는 하중·가진 조건을 고정하거나 조건별 기준을 따로 둬야 한다.

## 7. 한계

- Window는 독립 표본이 아니다(Ponte Moesa 60초 Window가 서로 겹침, HBTA 1-TAC는 Window 3개가 같은 값). 측정 단위 중앙값은 `summary.json`의 `per_block`에 있다.
- 표본이 작은 상태가 있다(Box DS5 12개, 정상 test 29개; Old ADA 정상 test 3회).
- HBTA 손상 상태는 상태마다 측정이 하나라, 손상 효과와 측정 시점·온도 효과를 구분할 수 없다.
- AI②는 사전 등록 전에 AI① v1·v2 판정과 test가 아닌 분할의 지표 값을 봤다(사전 등록서 0절).

## 8. 추가 해석 (2026-11-20, 결과 열람 후)

Box의 기준 상태 DS2는 철근 I·II·III을 노출한 **손상 상태**이고, Ponte Moesa에는 손상 없는 정상 상태가 없다. 그래서 3절의 Box 결과는 "정상 대비 손상"이 아니라 **"철근 노출 상태(DS2) 대비 변화"**로 읽는다. 3절의 오경보율은 진짜 오경보가 아니라 "DS2 test가 DS2 기준을 넘은 비율"이다. 사전 등록서와 위 결과 숫자는 바꾸지 않는다. 자세한 내용: `docs/AI2_PONTE_MOESA_BASELINE_NOTE.md`
