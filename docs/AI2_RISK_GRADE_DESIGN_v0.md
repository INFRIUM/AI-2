# AI② 위험 등급 설계 기준 v0 (Box, Truss)

작성일: 2026-11-04 · 상태: 초안 · 관련: Issue #10

## 1. 요약

- **등급의 정의:** 진동 데이터로 **점검 우선순위**를 알려 주는 4단계 경보다. 법정 안전등급이 아니고, 붕괴 가능성이나 내하력을 뜻하지 않는다.
- **Box 기준:** Ponte Moesa 논문의 **손상 진행 순서**(철근 → 긴장재 절반 → 긴장재 전체 + 복부 천공)
- **Truss 기준:** HBTA 논문의 **부재 중요도 × 손상 범위**. HBTA의 손상은 누적되지 않고 측정마다 보수되므로 순서로 나눌 수 없다.
- **임계값:** 아직 계산하지 않았다. AI① 데이터로 계산하고 6절의 조건을 통과해야 `risk_score`, `risk_level`을 출력한다.
- **XGBoost:** 공개 데이터에 D1~D3가 모두 있지 않으므로, 공개 데이터 단계에서는 4클래스 학습을 하지 않고 기준 상태 대비 점수로 평가한다. 코드는 삭제하지 않고, HW 모형 실험 데이터가 생기면 다시 검토한다.

| 등급 | 점수 | Box | Truss | 권장 조치 |
|---|---|---|---|---|
| 정상 | 0~25 | 기준 상태와 비슷함 | 기준 상태와 비슷함 | 계속 모니터링 |
| 주의 | 25~50 | 철근 절단 수준 | 안정용 부재 1곳 손상 수준 | 추이 관찰, 다음 점검 때 확인 |
| 경고 | 50~75 | 긴장재 일부 절단 수준 | 안정용 부재 여러 곳 또는 하중 전달 연결부 1곳 수준 | 조기 현장 점검 |
| 위험 | 75~100 | 긴장재 전체 절단 + 복부 단면 감소 수준 | 하중 전달 연결부 여러 곳 또는 주부재 연결부 수준 | 즉시 정밀 점검, 사용 제한 여부 검토 |

"수준"은 해당 손상을 넣은 공개 데이터의 점수로 임계값을 맞췄다는 뜻이다. 실제로 그 손상이 있다고 판정하는 것은 아니다.

## 2. 공통 원칙

| 원칙 | 내용 | 근거 |
|---|---|---|
| 교량별 기준 | 임계값은 교량마다 자기 기준 상태로 계산하며, 다른 교량에 그대로 쓰지 않는다 | Kamali 2024, Erduran 2021 |
| 등급과 측정의 분리 | 등급 경계는 문헌의 손상 내용으로 정하고, 진동 점수가 그 순서를 따르는지는 따로 검증한다 | 6절 |
| 진동수 단독 사용 금지 | Ponte Moesa에서 고유진동수는 손상에 둔감했고, 온도로 5~10% 변할 수 있다 | Garcia-Ramonda 2025, Svendsen 2021 |
| 조치 표현 | 부재 중요도와 필요 조치로 단계를 나누는 방식만 참고한다 | 시설물안전법 시행령 제12조, 별표 8 |

## 3. Box 기준 (Ponte Moesa Campagnola)

교량 조건: 긴장재 8개(복부당 4개)인 3경간 PSC 박스 거더교. 논문은 손상이 "증가하는 심각도"로 도입되었다고 설명하고, DS3·DS5·DS7을 "가장 중요한 손상"으로 분석했다.

| DS | 내용 (논문 표 1, 그림 6) | 등급 | 판단 근거 |
|---|---|---|---|
| DS0~DS1 | 피복 제거, 철근 노출 | 평가 제외 | 공사 영향이 크고 깨끗한 구간이 짧음 |
| DS2 | 위치 I·II·III 철근 노출 | **정상 (기준 상태)** | 논문이 기준 상태로 사용. 강재 절단 없음 |
| DS3 | 위치 II·III 철근 절단, 위치 IV 천공 | **주의** | 긴장재 절단 전 단계 |
| DS4 | 불명확 | 평가 제외 | 그림 6은 철근 손상, 본문은 긴장재 일부 절단으로 설명이 다름 |
| DS5 | 위치 II 긴장재 절반 절단 | **경고** | 전체 긴장재의 약 1/16(6%)에 해당, 프리스트레스 손실 시작 |
| DS6 | 위치 II 긴장재 전체 절단 | **위험** | 전체 긴장재의 1/8(12.5%)에 해당 |
| DS7 | DS6 + 위치 IV 천공 | **위험 (상한)** | 실험의 최종 상태 |

- 긴장재 비율은 개수로 계산한 값이며 내하력 계산이 아니다.
- 논문은 이 열화 유형이 "긴급한 조치를 요구하는 경우가 많다"고 설명한다(fib Bulletin 22 인용). 다만 위험 경계를 긴장재 전체 절단에 둔 것은 **팀의 설계 가정**이다.

**측정 방법**

| 항목 | 값 | 근거 |
|---|---|---|
| 주 지표 | 센서 쌍의 1-TAC, 3~12Hz, 60초 Window | 논문이 손상 심각도와의 상관을 확인한 방법 |
| 주 데이터 | S5 구성의 저진폭 구간 (RMS 0.008g 이하). DS2 기준, DS3·DS5·DS7 평가 | 논문과 같은 방법 |
| 교차 확인 | S1 야간 DS2와 DS6 (AI① 제안) | 정상과 위험의 비교 |
| 제외 | 센서 6번(고장) | 논문 |

## 4. Truss 기준 (Hell Bridge Test Arena)

교량 조건: 35m 단순 지지 리벳 강트러스교. 손상은 볼트를 제거해 넣었고, **측정 후 보수**한 뒤 다음 상태로 넘어갔다.

두 축으로 등급을 나눈다.
- **부재 중요도:** 저자가 교통 하중과 구조 안전에 **중요**하다고 분류한 연결부와, **덜 중요**하다고 분류한 안정용 부재
- **손상 범위:** 1곳, 여러 곳

| DS | 손상 부위 | 범위 | 저자의 중요도 | 등급 |
|---|---|---|---|---|
| UDS | 없음 | - | - | **정상** |
| DS3 | 세로보 가로재 | 1곳 | 낮음 | **주의** |
| DS5 | 수평 가새 연결부 | 1곳 | 낮음 | **주의** |
| DS6 | 수평 가새 연결부 | 1곳 | 낮음 | **주의** |
| DS4 | 세로보 가로재 | 여러 곳 | 낮음 | **경고** |
| DS7 | 수평 가새 연결부 | 여러 곳 | 낮음 | **경고** |
| DS1 | 세로보-가로보 연결부 | 1곳 | **높음** | **경고** |
| DS2 | 세로보-가로보 연결부 | 여러 곳 | **높음** | **위험** |
| DS8 | 가로보-주부재 연결부 | 1곳 | **높음** | **위험** |

- 저자의 중요도는 Svendsen 박사논문의 분류다. 등급 대응은 **팀의 설계 가정**이다.
- **Moderate, Low, High는 사용하지 않는다.** 박사논문 표 4.2의 이 값은 심각도가 아니라 **발생 가능성**이다.
- 저자는 모든 손상이 "기능을 완전히 잃은 상태"이지만, 여유 구조 덕분에 "즉각적인 구조 안전에는 치명적이지 않다"고 설명한다. 따라서 위험은 붕괴 임박을 뜻하지 않는다.
- 초기 균열처럼 경미한 손상은 이 데이터에 없다. 주의 등급의 근거가 약한 이유다.

**측정 방법**

| 항목 | 값 | 근거 |
|---|---|---|
| 주 지표 | AR(5) 계수의 Mahalanobis 거리 | Svendsen 2022 |
| 비교 지표 | 센서 쌍의 1-TAC | Box와 같은 지표로 비교 |
| 센서 | AG03, AG05의 y·z축 | AI① 제안. 가새와 가로재 손상은 주로 수평 방향에 영향을 줌 |
| 기준 데이터 | UDS 2개 측정 | 논문은 두 측정을 모두 기준으로 사용 |
| 제외 | 열차 통과 구간, 측정 초반의 가진 상승 구간 | AI① 보고 |

## 5. 점수와 등급 계산

**임계값**

| 임계값 | 위치 | 계산 방법 |
|---|---|---|
| T0 | 점수 0 | 기준 상태 지표의 중앙값 |
| T1 | 25, 정상/주의 | 학습에 쓰지 않은 기준 데이터의 상위 5% 값 |
| T2 | 50, 주의/경고 | 주의와 경고 지표 중앙값의 중간값 |
| T3 | 75, 경고/위험 | 경고와 위험 지표 중앙값의 중간값 |
| T4 | 100 | 위험 지표의 중앙값 |

**점수:** 지표값을 T0~T4 구간별로 선형 변환하고 0~100으로 제한한다.

**등급 변경 규칙 (설계 가정)**
- **상승:** 최근 3개 Window 중 2개가 해당 임계값을 넘으면 올린다. AI① `prediction`과 같은 규칙이다.
- **하강:** 최근 3개 Window 모두 임계값 아래일 때 내린다.
- **판정 보류:** 다음 경우에는 등급을 만들지 않고 이유를 표시한다.
  - 센서 고장 또는 결측
  - 가진 조건이 기준 범위를 벗어남 (Box의 RMS 초과, Truss의 열차 통과)
  - 온도가 기준 데이터 범위를 벗어남

## 6. 등급 출력 전 통과 조건

원본 데이터와 LIS2DW12 열화본 모두에서 확인한다. 모두 통과하기 전에는 `risk_score`와 `risk_level`을 `null`로 유지한다.

| # | 조건 | Box | Truss |
|---|---|---|---|
| 1 | 기준 데이터 오경보율 5% 이하 | 학습에 쓰지 않은 DS2 구간 | 학습에 쓰지 않은 UDS 구간 |
| 2 | 위험 탐지율 95% 이상 | DS6, DS7 | DS2, DS8 |
| 3 | 등급 순서 유지 | 중앙값 DS2 < DS3 < DS5 < DS7 | 중앙값 정상 < 주의 < 경고 < 위험 |
| 4 | 손상 범위 순서 유지 | - | DS2 > DS1, DS4 > DS3, DS7 > DS5·DS6 |
| 5 | 상태 일반화 | 상태 1개를 뺀 검증에서 등급 경계가 유지됨 | 같음 |

조건 1, 2의 수치는 Kamali 2024의 값이다. 4번은 Svendsen 2022가 수직 센서 40개에서 관찰한 순서다.

**통과하지 못하면**
- **조건 3 실패:** 해당 교량의 인접 등급을 합쳐 3단계 이하로 줄인다.
- **조건 2 실패 또는 열화본에서 분리 안 됨:** 해당 교량은 "기준 대비 이상 여부"만 표시한다.
- 임계값을 맞추기 위해 평가 데이터를 반복해서 다시 고르지 않는다.

Truss는 통과가 쉽지 않을 수 있다. 논문은 센서 40개에서 오경보율 6.3%였고, 20개로 줄이면 미탐지가 16~22%로 늘었다. 우리는 센서가 2개다.

## 7. HW 축소 모형 적용

공개 데이터의 임계값을 그대로 쓰지 않는다.

1. 모형의 손상 전 측정으로 T0, T1을 다시 계산한다.
2. T2~T4는 공개 데이터의 비율(T2/T1 등)을 초깃값으로 쓴다.
3. 3축 데이터와 대역을 모형의 고유진동수에 맞춰 다시 정한다.
4. D1~D3 × L1~L3 실험으로 등급 순서를 확인한다.

| HW 손상 | 공개 데이터 근거 | 상태 |
|---|---|---|
| D1 연결부 풀림 | HBTA 연결부 손상 | Truss만 있음 |
| D2 지지조건 변경 | 없음 | **HW 실험으로만 판단 가능** |
| D3 부재 강성 변경 | Ponte Moesa, HBTA 가로재 | 있음 |

## 8. 한계

- **측정 기간이 짧고 계절 변화가 없다.** 두 데이터셋 모두 교량 1개를 단기간 측정한 것이고, 장기 운영 조건도 없다.

| 데이터셋 | 측정 기간 | 온도 정보 | 등급 설계에 미치는 영향 |
|---|---|---|---|
| Box: Ponte Moesa | 2019-11-26~29 (4일, 연속 기록) | 가속도 파일에 온도 열 없음 | 일교차 수준의 변화만 포함. 온도 영향을 정량화할 수 없음 |
| Truss: HBTA | 2020-09-22~28 (약 1주, AI① 표의 노이즈 측정 기준. 연도는 박사논문 기준, 전체 측정은 더 길 수 있음) | 측정별 10~22°C | 초가을 범위만 포함. DS3, DS4는 약 21~22°C로 다른 측정보다 8°C 이상 높음 |

  일반적으로 고유진동수는 온도 때문에 일간·계절 단위로 5~10% 변할 수 있다(Svendsen 2021). 따라서 임계값은 **측정 당시의 환경에서만 유효**하고, 다른 계절이나 다른 온도에서의 오경보율은 이 데이터로 알 수 없다. 보완 방법은 다음과 같다.
  - 기준 데이터의 측정 기간과 온도 범위를 임계값과 함께 기록한다.
  - 온도 기록이 있으면 그 범위를 벗어날 때 등급을 보류한다(5절). 온도 기록이 없는 Ponte Moesa는 이 규칙으로 걸러 낼 수 없으므로, 저진폭 구간 필터와 야간 교차 확인으로 대신한다.
  - HW 모형은 DS18B20으로 온도를 함께 기록하고, 가능한 한 여러 온도에서 기준 데이터를 측정한다.
  - 계절 변화까지 검증했다고 주장하지 않는다.
- 두 실험 모두 내하력을 평가하지 않았다. 위험은 **"실험에서 가장 심한 상태 수준"**이라는 뜻이다.
- 기준 데이터가 적어 상위 5% 값도 불안정할 수 있다. Window는 서로 독립이 아니므로 결과는 측정·블록 단위로도 보고한다.
- Ponte Moesa는 프리스트레스 콘크리트교의 결과라 저자도 다른 구조로의 일반화를 경고한다.
- Svendsen 2023은 SAGE 원문 접근이 막혀, 같은 내용이 들어 있는 박사논문 4장으로 확인했다.

## 9. AI①에 요청할 사항

| # | 요청 |
|---|---|
| 1 | HBTA DS1~DS8 정의는 Svendsen 2022 표 1로 확정. DS는 누적이 아니라 **측정마다 보수**된 상태 |
| 2 | Ponte Moesa DS 경계와 DS4 내용을 논문 표 1, 그림 6, 표 S2, 원본 기록으로 확정 |
| 3 | Ponte Moesa 주 데이터로 S5 저진폭 구간 검토, 단위(g) 확인 |
| 4 | 1-TAC와 AR(5) 계수 추가 |
| 5 | HBTA UDS 이름 확인. 날짜와 온도로 보면 `UDS_02`(09-22, 10°C)가 논문의 UDS1(손상 전), `UDS_01`(09-27, 13°C)이 UDS2(손상 후)로 보임 |
| 6 | HBTA 분할 재검토. `UDS_01`을 모두 AI①이 쓰면 AI② 기준이 열차가 포함된 측정 1개뿐이므로, 두 측정을 시간 블록으로 나눠 함께 쓰는 방안 협의 |
