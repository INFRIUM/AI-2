작성일: 2026-11-19 · 상태: **고정 (확인용 데이터 처리 전)** · 관련: Issue #16, #15, #13, PR #14, INFRIUM/AI-1#3, INFRIUM/AI-1#4

## 0. 이 문서의 목적과 고정 시점

- 이 문서는 HBTA 스윕 가진(SM) **확인용 측정 34개**로 Truss의 **정상/이상 구분**을 한 번 평가하는 규칙을 고정한다.
- 이 문서와 평가 코드를 커밋하고 Push한 뒤에 AI①이 확인용 측정을 처리한다(`AI1-public-1.2`). 커밋 시각과 문서 SHA-256이 고정 시점의 증거이고, 실행 결과에 이 문서의 SHA-256을 기록한다.
- 결과를 본 뒤 규칙을 바꾸지 않는다. 오류가 발견되면 v3로 새로 등록하고 v2 결과와 함께 보고하며 "결과 열람 후 변경"을 표시한다.
- **위험 등급(4단계)은 이 문서에서 검증하지 않는다.** 진행 원칙(AI-2#15 2절 원칙 2) "정상/이상 구분 먼저, 등급 단계는 나중"에 따라, 구분을 통과한 경우에만 다음 등록에서 등급을 다룬다. 이 문서의 등급 관련 값은 서술만 한다(8.5절).

## 3. 측정 역할

**주 평가: SM, 가진 위치 P2, 가진 방향 Z** (`AI1-public-1.1` NM과 같은 위치·방향)

| 역할 | 측정 | 날짜 | 온도 | 기차 통과 |
|---|---|---|---|---|
| 정상 기준 | `MVS_P2_UDS_SM_Z_01` | 9/27 | 13°C | 아니요 |
| 오경보 확인 | `MVS_P2_UDS_SM_Z_02` | 9/22 | 10°C | 예 |
| 탐지 확인 (위험) | `MVS_P2_DS2_SM_Z_01`, `MVS_P2_DS8_SM_Z_01` | 9/28, 9/27 | 15, 12°C | 예, 아니요 |
| 탐지 확인 (그 밖) | `MVS_P2_DS{1,3,4,5,6,7}_SM_Z_01` | 9/27–28 | 13–21°C | 섞임 |

**보조 평가: 나머지 SM 손상 측정 24개** (P1 Y, P1 Z, P2 Y의 DS1–DS8). 정상 기준은 같은 조건의 개발용 `_01` 측정이다. 이 조건들의 정상 데이터는 이미 봤으므로 오경보는 개발용 값으로만 서술하고, 통과 판정에 쓰지 않는다(8.3절).

## 4. Window 정렬과 사용 Window

- **정렬:** 측정 시작부터의 시간(`window_start_s`)이 같은 Window끼리 비교한다. 개발용 6개에서 두 날짜의 가진기 주파수가 같은 시각에 맞았다(5-3: 차이 중앙값 0.02–0.2Hz, 가장 잘 맞는 이동 0 Window).
- **`AS` 확인:** 확인용 측정마다 기준 측정과 같은 시각의 `AS` 우세 진동수 차이 |log f_기준 − log f_대상|의 중앙값을 Window 이동 −3…+3에서 계산한다. 가진기가 켜진 Window(두 측정 모두 `AS` RMS ≥ 1m/s²)만 쓴다. 중앙값이 가장 작은 이동(같으면 0에 가까운 쪽)을 "가장 잘 맞는 이동"으로 한다. 상관은 쓰지 않는다(로그 스윕에서는 이동과 관계없이 같은 값이 나옴). 가장 잘 맞는 이동이 0이 아니면 그 측정을 "정렬 이상"으로 표시하고, **이동 없이** 평가한 결과와 이동을 적용한 결과를 둘 다 보고한다. 판정은 이동 없이 평가한 결과로 한다.
- **`AS`의 용도 제한:** `AS`는 정렬 확인에만 쓴다. 지표 계산과 판정에는 쓰지 않는다(가진기가 교량 위에 있어 교량 응답이 섞일 수 있음).
- **사용 Window:** 기준 측정과 대상 측정에서 **둘 다 보류가 아닌** 같은 시각의 Window.

## 5. 지표: 같은 시각 AR 차이

- 특징값 x(t): 열화본 z AR(5) 계수 10개 (`acc01_ar1_z`–`acc01_ar5_z`, `acc02_ar1_z`–`acc02_ar5_z`), Window 하나(10.24초)씩. 여러 Window를 평균하지 않는다.
- 기준 b(t): 정상 기준 측정의 같은 시각 Window 값.
- 척도 s_j: 정상 기준 측정의 **사용 가능한 모든 Window**(보류 제외)에서 계수 j의 표준편차(ddof=1).
- **거리 d(t) = √( (1/10) Σ_j ((x_j(t) − b_j(t)) / s_j)² )**

값이 클수록 같은 시각의 정상 기준과 다르다.

## 6. 기준값과 판정

- **기준값 T = 2.6795597336** (고정값)
  - 계산: 개발용 SM 3개 조건(P1 Y, P1 Z, P2 Y)에서 양방향(각 날짜를 기준으로)으로 구한 d(t) 204개의 99번째 백분위수(`numpy.percentile`, linear).
  - 선택 근거(5-4): 조건 하나를 빼고 나머지로 T를 정해 뺀 조건에 적용하는 시험 6번에서, 이 규칙(1 Window, 3번 중 2번, p99)만 모두 오경보 5% 이하였다.
- **Window 판정:** 시간순으로 연속한(10.24초 간격) 사용 Window 3개(t−2, t−1, t) 중 **2개 이상이 d > T이면 t를 "이상"**, 아니면 "정상".
- 앞의 두 Window가 없거나 연속하지 않으면 t는 "판정 불가"로 따로 세고, 비율 계산에서 뺀다.

## 8. 보조 분석 (통과 판정 없음)

### 8.1 구분 가능성 상한

주 평가 조건에서 오경보 확인 측정(`_02`)의 d(t)와 위험 상태(DS2+DS8)의 d(t)를 비교한다.

| 값 | 정의 |
|---|---|
| AUC | 위험 Window의 d가 `_02` Window의 d보다 클 확률 (동점 0.5) |
| 상한 탐지율 | T 대신 `_02` d의 95번째 백분위수를 기준으로 했을 때의 위험 탐지율 (연속 판정 없이) |

상한 탐지율은 확인용 정상 데이터로 기준을 정한 값이라 **성능 주장에 쓰지 않는다.** 실패 원인이 "기준값 선택"인지 "정상과 위험이 겹침"인지 구분하는 데만 쓴다.

### 8.2 원인 분석 (원본)

같은 Window로 원본 z AR(5)에 5–7절을 적용한다. 원본 기준값은 개발용에서 같은 방법으로 구한 **T_raw = 2.0605781871**이다. 원본 y+z AR(계수 20개)은 개발용 기준값이 없으므로 8.1절의 AUC만 보고한다.

| 결과 | 기록 |
|---|---|
| 열화본 실패, 원본 z 통과 | 센서 잡음 |
| 원본 z 실패, 원본 y+z AUC ≥ 0.99 | y축 손실 |
| 원본 z 실패, 원본 y+z AUC < 0.99 | 하루치 정상 기준 또는 데이터 한계 |

원인과 관계없이 열화본 실패는 실패다.

### 8.3 다른 조건의 탐지 (P1 Y, P1 Z, P2 Y)

- 각 조건의 손상 8개 측정에 5–6절을 그대로 적용한다. 정상 기준은 그 조건의 개발용 `_01` 측정, T는 같은 값이다.
- 위험 탐지율(DS2+DS8)과 상태별 탐지율을 보고한다. 그 조건의 오경보율은 개발용 `_02`로 계산한 값을 "개발용(이미 본 데이터)"으로 표시해 함께 적는다.
- 옆방향 가진(Y) 조건은 열화본 y축이 살아 있는 Window가 많다. 열화본 y+z AR의 AUC도 참고로 보고한다.

### 8.4 AI① v1 판정 (참고)

확인용 34개에 대한 AI① v1 `prediction`의 Anomaly 비율을 측정별로 보고한다. v1은 NM으로만 학습했으므로 해석하지 않는다.

### 8.5 등급 서술

주 평가 조건의 상태별 d(t) 중앙값을 v1 기대 등급(주의: DS3·DS5·DS6, 경고: DS1·DS4·DS7, 위험: DS2·DS8)과 함께 표로 적는다. 순서가 맞는지 서술만 하고 통과 판정은 하지 않는다.

## 10. 함께 보고할 한계

- **정상 기준이 하루치:** HBTA SM에는 조건마다 정상 측정이 2일치뿐이라, 날짜에 따른 변동을 충분히 알 수 없다. 오경보 확인도 다른 날 하루뿐이다.
- **독립성:** SM 측정은 NM과 같은 기간, 같은 손상 상태를 가진 방식만 바꿔 잰 것이다. 손상 상태마다 측정이 하나라 상태 차이와 측정 시점 차이(날짜, 온도, 기차 통과)를 구분할 수 없다. 특히 DS3·DS4는 21°C로 다른 측정(10–15°C)보다 따뜻하다.
- **실제 운영과의 차이:** 같은 가진 주파수 시점끼리 비교하는 방법은 가진을 알 때만 쓸 수 있다. 실제 교량(차량, 바람)에는 그대로 쓸 수 없다. 이 평가가 보여 주는 것은 "가진 조건이 같고 정상 기준이 하루치일 때 열화본 z AR이 손상을 구분하는가"까지다.
- **기준 측정 일부 열람:** `MVS_P2_UDS_SM_Z_01`은 AI①이 요약값을 본 적이 있다. 이 측정은 기준으로만 쓰고 오경보 확인에는 쓰지 않는다.
- **표본 수:** 오경보 확인 Window는 30개 안팎으로 예상한다. 1개 차이가 약 3%p다.
